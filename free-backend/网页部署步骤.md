# Cloudflare 网页部署

## 1. 数据库

在 Cloudflare 的 D1 SQLite database 创建 youyue-bookings，保存 Database ID。进入 Console，粘贴 schema-console.sql 的完整内容并执行。应建立 profiles、bookings、reminders、service_tokens、rate_limits 五张表和七个触发器。

可使用下面的检查语句：

```sql
SELECT type, COUNT(*) AS count FROM sqlite_master
WHERE (type='table' AND name IN ('profiles','bookings','reminders','service_tokens','rate_limits'))
OR (type='trigger' AND name IN ('conflict_insert','conflict_update','reminder_create','reminder_recipient','reminder_stop','reschedule_send_lock','reminder_reschedule'))
GROUP BY type;
```

初始化语句使用 IF NOT EXISTS，不删除已有记录。检查应返回 table=5、trigger=7。

## 2. Worker

Workers & Pages 创建应用，选择 Hello World，名称 youyue-free-backend。进入 Edit code，将 worker-dashboard.mjs 完整内容替换默认代码，保存部署。在 Bindings 添加 D1 database，名称 DB，选择刚创建的数据库。

## 3. 变量与 Secret

在 Production 的 Variables and secrets 添加：

| Key | 类型 | 值 |
| --- | --- | --- |
| WX_APPID | Text | 自己的微信 AppID |
| WX_APP_SECRET | Secret | 自己的微信 AppSecret |
| SESSION_SECRET | Secret | 自己生成的随机签名密钥，至少32字符 |
| REMINDER_TEMPLATE_ID | Text | 真实微信订阅模板 ID |
| REMINDER_TITLE_FIELD | Text | 活动名称字段，例如 thing1 |
| REMINDER_TIME_FIELD | Text | 活动时间字段，例如 time2 |
| REMINDER_LOCATION_FIELD | Text | 地点字段，例如 thing3 |
| MINIPROGRAM_STATE | Text | 体验版用 trial，正式发布后用 formal |

模板只包含活动名称、时间、地点三个字段；编号必须与实际模板一致。更多必填字段需要调整消息组装。Secret 只填写到后台。

## 4. 定时任务

在 Settings 的 Trigger events / Cron Triggers 添加表达式 `* * * * *`，保存。它每分钟扫描到期提醒，不是每分钟向用户发送消息。新增定时配置生效存在延迟。

## 5. 接入

在普通手机浏览器打开实际生产地址 /health，确认两个配置状态为 true，再验证微信公众平台的 request 合法域名是否接受该主机地址。原地址手机不可达时，先验证 [Pages 入口](../free-entry/网页部署步骤.md)。

完成后填写客户端配置，编译、上传体验版，用两位体验成员验收。平台认证或备案要求由账号条件决定，不能通过此代码免除。

参考：[官方 D1 教程](https://developers.cloudflare.com/d1/get-started/)。
