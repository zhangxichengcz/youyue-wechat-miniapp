# 可选 Pages 入口

此入口通过 Service binding 调用同账号现有的 youyue-free-backend，不额外保存微信密钥，也不建立第二份预约数据库。Pages Functions 与 Workers 使用共享请求额度；需在自己的 Free 账号中部署。

## 先验证地址

将 public 文件夹中的 _worker.js 和 index.html 放在上传 ZIP 根目录。Cloudflare Workers & Pages → Create application → Pages → Drag and drop / Upload assets。填写自己的项目名，上传并部署。

记录控制台实际生成的生产 Pages 地址。用手机 Wi-Fi 与移动网络分别访问该地址 /reachability，应看到 ok=true、reachable=true。它只验证这个入口能访问，不证明后台已连通。不同网络可达性仍需实际测试。

## 绑定后台

访问测试通过后，在 Pages Settings → Bindings → Add → Service binding 添加 BACKEND，Service 选择 youyue-free-backend，环境为 Production。保存后重新部署同一份入口文件，让绑定生效。

手机打开实际 Pages 地址 /health，应看到原后台返回的 configured=true、remindersConfigured=true。

## 切换客户端

在微信公众平台添加 Pages 生产主机地址到 request 合法域名，确认保存。将 miniprogram/config.js 的 apiBase 改为实际地址，不带 /health 或 /reachability。保持原 Worker 和定时任务，重新编译、上传并设置体验版。

随后通过手机微信验证登录、预约读取、双方确认与提醒。原后台检查成功不能替代微信内部请求和账号权限检查。

参考：[网页上传支持 _worker.js](https://developers.cloudflare.com/pages/get-started/direct-upload/)、[Service binding](https://developers.cloudflare.com/pages/functions/bindings/#service-bindings)、[免费配额](https://developers.cloudflare.com/pages/functions/pricing/#free-plan)。
